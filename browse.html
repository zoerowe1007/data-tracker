How to use this page

Each row is one item (a coin, a weather city or an air-quality city) with its latest readings from the most recent run. The column groups tell you which source a reading comes from; an empty dash — means that source does not report that reading for that item.

  • Narrow it down: pick a data source or group, or type part of a name.
  • Sort: click any column heading (or use the Sort box) to order by that reading; click again to flip up and down.
  • Keep a shortlist: click ☆ to star an item, then press ★ Shortlist to see only your stars. Stars stay in this browser.
  • Go deeper: click an item name to see how it moved on the Trends page. Hover a column heading for what it means.
